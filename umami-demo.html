Roadmap · 从演示到全自动预订

The assistant you are testing is Phase 1 (live now). Here is how it evolves — and what it needs from you.
Phase 1 · 现已上线

对话式咨询 + 预订引导

营业时间、菜单、团体政策、过敏处理方式、分店信息——全部即时准确回答（6 种语言）。预订通过您的官方链接完成，AI 不碰预订系统。

需要的权限：无 — 已就绪。仅需网站管理员放置一个验证文件 + 嵌入一段代码即可上 umami-restaurant.com。

Phase 2 · 下一步（1-2 周可开通）

对话式代办：AI 收集并发送预订

客人说"明天 4 点 4 个人，一位花生过敏，回执发到 xx@邮箱"→ AI 反问哪家分店 → 逐项收集（分店/日期/时间/人数/姓名/联系方式/过敏原）→ 结构化预订邮件自动发送到对应分店邮箱，客人即时收到"已受理"回执。餐厅在自己的 Guestplan 里照常录入、电话/邮件确认。

需要的权限：① 授权 AI 以 umami-restaurant.com 分店邮箱为目的地发送预订邮件；② 确认各店接收预订的邮箱地址；③ 隐私条款补充一条（预订信息含过敏原说明，仅用于本预订）。

Phase 3 · 终态（试点评审后）

直连 Guestplan：实时查桌 + 自动下单

AI 实时查询真实可用时段 → 客人选定即写入 Guestplan → 确认邮件自动发出，全程无人工。冲突时自动推荐最近的可用时段。

需要的权限：① Guestplan API 对接授权（贵方调研清单已注明：技术对接请联系 Han Ji，由其指派负责人）；② Guestplan API 账号/密钥；③ 试点评审会上确认扩展范围与商务条款。

⚠️ 无论哪个阶段，AI 的承诺红线不变：未获餐厅确认前，绝不向客人声称"已预订成功"。 过敏原等健康相关信息只进入预订执行通道（邮件/API），绝不用于其他用途。
